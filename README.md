# Kommo для Claude — One Development

[![Проверка на Windows и Mac](../../actions/workflows/test.yml/badge.svg)](../../actions/workflows/test.yml)

Дополнение к коннектору One Development: Claude начинает читать Kommo.
Для сотрудников, у которых коннектор уже установлен и через него работает почта.

- **Только чтение.** Менять и удалять в Kommo Claude ничего не может.
- **Только ваши сделки**, контакты, задачи и примечания — закреплённые за вами.
- **Вход своим логином Kommo**: Claude видит не больше, чем вы сами в Kommo.
- **Почту и папку ai-office не трогает**, пароль от почты не спрашивает.

## Скачать

**[OneDev-Kommo.zip](../../releases/latest/download/OneDev-Kommo.zip)**

Понадобится ещё **ключ Kommo** — строка из письма Дмитрия. В архиве и в этом репозитории ключа нет.

## Как поставить (5 минут)

1. Распакуйте архив: правый щелчок → «Извлечь всё» (Windows) или двойной щелчок (Mac).
2. **Windows:** двойной щелчок по `Kommo-Windows.cmd`.
   Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   **Mac:** двойной щелчок по `Kommo-Mac.command`.
   Если Mac пишет «не удаётся открыть» — правый щелчок по файлу → «Открыть» → «Открыть».
3. Вставьте ключ из письма и нажмите Enter. Должно появиться «Готово.»
4. Закройте Claude полностью (Windows: значок в трее → Quit; Mac: ⌘Q) и откройте снова.
5. Напишите в Claude: «Войди в Kommo». Откроется страница Kommo — войдите своим логином и паролем Kommo.
6. Проверьте: «Покажи статус Kommo». Должно быть ваше имя и «только чтение».

Если что-то не так — пришлите Дмитрию снимок экрана.

## Что происходит при установке

- Программа коннектора в `~/.onedev-connector/app` обновляется до версии 0.2.2, старая остаётся рядом (`index.js.before-kommo`).
- Ключ Kommo уходит в хранилище системы: на Windows — файл, зашифрованный DPAPI под вашей учётной записью; на Mac — связка ключей. В настройках Claude остаётся только ссылка на него.
- В настройки Claude (`claude_desktop_config.json`, и `ai-office/.mcp.json` для вкладки Code) дописывается Kommo в режиме «только чтение». Перед изменением делается копия `*.before-kommo`.
- В конце установщик сам проверяет: инструменты Kommo на месте, записи нет, почта по-прежнему отвечает.

## Проверка

Каждое изменение проверяется на чистых машинах GitHub: Windows Server 2025, Windows Server 2022 и macOS.
Kommo в проверках поддельный, ключ тестовый, настоящие данные не используются.

```
npm ci
npm test
```

- `test/kommo-e2e.mjs` — 62 проверки коннектора: режимы, «только свои», личный вход, журнал и откат.
- `test/install-e2e.mjs` — установка как у сотрудника: уже стоит коннектор с почтой → запуск `Kommo-Windows.cmd` с ключом → вход в Kommo → чтение своих сделок; неверный ключ ничего не меняет, повторный запуск безопасен.
