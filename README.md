# Kommo для Claude — One Development

[![Проверка на Windows и Mac](../../actions/workflows/test.yml/badge.svg)](../../actions/workflows/test.yml)

Коннектор Kommo для Claude. Только Kommo, без почты.

- **Только чтение.** Менять и удалять в Kommo Claude ничего не может.
- **Только ваши сделки**, контакты, задачи и примечания — закреплённые за вами.
- **Вход своим логином Kommo** на странице Kommo: Claude видит не больше, чем вы сами в Kommo.
- **Никаких ключей вводить не нужно.** Секрет интеграции хранится на странице входа, на ваш компьютер он не попадает.

## Установка (5 минут)

**1.** Откройте Claude → вкладка **Code** и вставьте:

```
Установи коннектор Kommo для One Development. Скачай архив
https://github.com/aimasterybiz-sys/onedev-kommo-claude/releases/latest/download/OneDev-Kommo.zip
во временную папку, распакуй и запусти установщик из папки OneDev-Kommo:
на Windows — Kommo-Windows.cmd с параметром auto, на Mac — bash Kommo-Mac.command auto.
Установщик не меняй. Когда закончит, покажи мне его последние строки.
```

Если Claude спросит разрешение выполнить команду — разрешите. В конце должно быть «Готово.»

**2.** Закройте Claude полностью (Windows: значок в трее → Quit; Mac: ⌘Q) и откройте снова.

**3.** Напишите в Claude: **«Войди в Kommo»**. Откроется страница Kommo — войдите своим логином и паролем Kommo.

**4.** Проверьте: **«Покажи статус Kommo»** — должно быть ваше имя и «только чтение».

Без Claude: скачайте [OneDev-Kommo.zip](../../releases/latest/download/OneDev-Kommo.zip), распакуйте и дважды щёлкните `Kommo-Windows.cmd` (или `Kommo-Mac.command`), дальше — с шага 2.

## Что делает установщик

- Ставит программу коннектора в `~/.onedev-kommo`. Если Node.js 20+ на компьютере нет, скачивает официальный с nodejs.org со сверкой SHA-256.
- Записывает коннектор `onedev-kommo` в настройки Claude (`claude_desktop_config.json`) в режиме «только чтение». Копия прежних настроек — `claude_desktop_config.json.before-kommo`.
- Почтовый коннектор One Development и другие настройки Claude не трогает.
- В конце сам проверяет: инструменты Kommo на месте, записи нет, почты нет.

Пароль Kommo вводится только на странице Kommo. После входа Claude хранит доступ в хранилище системы
(Windows — DPAPI под вашей учётной записью, Mac — связка ключей) и обновляет его сам.

## Проверка

Каждое изменение проверяется на чистых машинах GitHub: Windows Server 2025 (без Node.js), Windows Server 2022 и macOS.
Kommo и страница входа в проверках поддельные, настоящие данные не используются.

```
npm ci
npm test
```

- `test/kommo-e2e.mjs` — проверки коннектора: режимы, «только свои», личный вход, вход через страницу входа без секрета, журнал и откат.
- `test/install-e2e.mjs` — установка как по промту: уже стоит почтовый коннектор → `Kommo-Windows.cmd auto` → вход в Kommo → чтение своих сделок; почтовый коннектор не тронут, повторный запуск безопасен.

Страница входа и обмен кода на доступ: `onedev-kommo-login.vercel.app` (`/kommo`, `/api/token`).
